# Weather Dashboard

A highly visual meteorological application providing precise hyper-local forecasting with interactive maps and historical data visualization.

## Tech Stack
- **Frontend**: React, D3.js, Tailwind CSS
- **API**: OpenWeatherMap API
- **Charts**: D3.js, Recharts

## Getting Started
```bash
npm install
cp .env.example .env
# Add your VITE_OPENWEATHER_API_KEY from openweathermap.org
npm run dev
```

## Features
- Current weather with detailed stats
- 7-day and hourly forecasts
- Interactive temperature/precipitation charts
- Location search with geolocation
- Wind speed, humidity, UV index tracking
- Historical data comparison
